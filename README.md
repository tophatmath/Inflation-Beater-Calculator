# Inflation-Beater-Calculator
Find out if your INVESTMENTS beat inflation throughout different years

A console-based C++ program that helps users determine whether an investment
has beaten inflation by comparing **nominal CAGR** against **inflation-adjusted CAGR**.

---

## Features
- Supports multiple investments
- Calculates:
  - Nominal CAGR
  - Inflation CAGR
  - Real CAGR
- Determines whether an investment beats inflation
- Uses yearly inflation rates for accuracy

---

## Requirements
- C++ compiler (GCC / MinGW / g++)
- Windows, Linux, or macOS
- Terminal / Command Prompt

---
